# Registro de Decisiones de Arquitectura (ADR)

Este directorio documenta las decisiones de arquitectura significativas del
proyecto Adelson (AdelsonWeb + AdelAI). Cada decisión se registra en un ADR
independiente con el siguiente formato:

- **Título** — nombre descriptivo de la decisión.
- **Estado** — `Propuesto`, `Aceptado`, `Obsoleto` o `Reemplazado` (con referencia al ADR que lo reemplaza).
- **Fecha** — fecha de la decisión.
- **Contexto** — situación y restricciones que motivan la decisión.
- **Decisión** — qué se decidió y cómo se implementa.
- **Justificación** — por qué se eligió esta opción.
- **Alternativas consideradas** — opciones evaluadas y motivos de descarte.
- **Consecuencias** — impacto positivo, negativo y neutro.
- **Migración / Impacto** — trabajo pendiente o realizado para materializar la decisión.
- **Referencias** — commits, documentos y código relacionados.
